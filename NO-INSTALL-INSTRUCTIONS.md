## How to Add a Cafe Menu

1. **Visit a cafe's Square ordering website** in a new tab (the website where you'd order food/drinks)

2. **Get the page source:**
   - **Windows:** Right-click on the page → "View Page Source" (or press `Ctrl + U`)
   - **Mac:** Right-click on the page → "View Page Source" (or press `Cmd + Option + U`)

3. **Copy everything:**
   - **Windows:** Press `Ctrl + A` (select all) then `Ctrl + C` (copy)
   - **Mac:** Press `Cmd + A` (select all) then `Cmd + C` (copy)

4. **Go back to the Cafe Scraper tab** → Click "Add Cafe" → Paste in the big box → Click "Extract Menu"

Done! The menu is now saved in your browser.

## Troubleshooting

**Q: The file won't open**
A: Make sure the file ends with `.html` - if it says `.txt`, rename it to `.html`

**Q: My data disappeared**
A: If you clear your browser data/cache, it will erase the saved cafes. Always keep the HTML file safe and you can start over.

**Q: Can I use this on my phone/tablet?**
A: Yes! Just transfer the HTML file to your device and open it in a mobile browser.
